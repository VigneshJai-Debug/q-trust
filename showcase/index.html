Quick start

qtrust — zsh
# 60 seconds — scan a live endpoint
$ git clone https://github.com/humoge7502/q-trust && cd q-trust/inspector
$ pip install -e .
$ crypto-inspector scan example.com --risk --compliance nist,cnsa
✓ CBOM → cbom.json (CycloneDX 1.7) · risk + compliance report

# 10 minutes — full stack on Docker
$ cd .. && cp .env.example .env && docker compose up -d --build
$ ./scripts/verify_all.sh
✓ 9-step full-stack verification
→ dashboard http://localhost:3000 · api :3001 · grafana :3002
