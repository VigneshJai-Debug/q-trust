# ADR index

Architecture decisions are recorded as lightweight Architecture Decision
Records (Nygard format: Status / Context / Decision / Consequences). New ADRs
get the next sequential number and are never edited after acceptance — a
reversal is recorded as a new ADR superseding the old one.
